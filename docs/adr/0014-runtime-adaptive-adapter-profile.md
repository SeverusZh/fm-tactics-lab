# ADR-0014 运行时适配画像与自动重定位

- 状态：已采纳
- 日期：2026-11-19
- 决策者：仓库维护者

## 背景

ADR-0013 以参考构建的 PE 布局、关键 range 摘要和 VTable 身份做 fail-closed 兼容门禁。2026-11-18 的 Steam 自动更新把游戏升级到 BuildID 26620374；本机 `game_plugin.dll` 的装载镜像在参考 RVA 上与 2503222 画像的 78 个 range 全部不符，宿主因此拒绝加载。此前每次游戏更新都要重新生成画像、重新编译宿主，玩家的存档与战术能力也随之中断。

公开仓库不能写入游戏原始字节，安装包也不能分发游戏 DLL 或宿主。兼容方案必须同时满足：不上传游戏内容、不因每次更新重编宿主、错误画像不能静默加载。

## 决策

1. 原生宿主接受运行时画像 `adapter_profile.txt`。画像以安装镜像的 SHA-256 绑定，内容为参考 RVA 到安装镜像 RVA 的映射；宿主启动时优先读取 `FM27_ADAPTER_PROFILE`，否则读取可执行文件同目录的 `adapter_profile.txt`。
2. 宿主仍以编译期参考画像定义调用契约。`at()` 只把参考 RVA 换成运行时 RVA；未映射的锚点立即以 252 退出，不返回错误地址。画像中的目标超出镜像范围、镜像哈希不符、`reference` 与宿主参考 id 不符或 `missing` 非零时，`known_image` 拒绝加载。`partial 1` 只允许 `--check-image` 与 `--probe-engine` 诊断入口；正式比赛一律拒绝部分画像。
3. 公开的 `native/profile_metadata.json` 增加 `signatures`：参考函数的掩码窗口摘要和操作数描述，不含原始游戏字节；`reference` 身份与每个 range 的摘要校验后才允许写回。`scripts/adapt_profile.py` 用这些摘要在本机 DLL 中定位函数、传播调用与数据引用，生成运行时画像和覆盖报告。参考 DLL 只在开发者本地用于生成摘要。
4. 激活通过安装镜像导出的 `WaitForActivation` 完成：宿主在可取消的 15 秒等待内调用该导出，不解析或轮询每个构建移动的 `.00cfg` 字。导出缺失时才回退到画像给出的激活地址或编译期 flag，并校验目标位于镜像 section。`--probe-engine` 只做加载、指纹与激活诊断，不创建引擎接口。
5. 运行时画像当前只面向 Steam 构建；Epic 宿主继续使用 ADR-0013 的摘要 range 契约，不读取运行时画像。运行时画像只作为数据分发；安装包仍不包含游戏 DLL、宿主二进制或游戏字节。生成失败时继续 fail-closed，并输出缺失锚点清单。

## 后果

- 小型热修只要参考函数的掩码窗口仍能定位，重新生成画像即可，无需重编 `FM27Simulator.exe`；画像与镜像哈希一一绑定，换 DLL 后旧画像失效。
- BuildID 26620374 是一次较大更新：当前自动定位覆盖 57/99 个 `at()` 锚点，剩余代码、VTable 与数据槽需要在画像中补齐；在补齐前本机原生实验继续被宿主拒绝，界面应把 `adapter_profile_incomplete` 与缺失锚点数量作为可诊断原因展示。
- 掩码窗口摘要比整段函数字节更耐重定位和局部重编译，但函数被重写时仍可能无法定位；此时报告缺失锚点比猜测目标地址安全。
- 公开元数据体积增加约 0.6 MB；源码清单和 OpenAPI 不受影响。
- 执行编辑实验仍只接受已验证的参考镜像；运行时画像只解锁普通比赛，不解锁 `native_execution_experiment.h` 的写操作，宿主记录 `execution_reference_only` 后以 244 拒绝。
- 2026-11-19 试验：在 75 个映射（含临时占位）下，宿主完成加载/激活、资源索引、引擎 bootstrap、fixture 反序列化、preparation 与模拟 tick 0，随后在 `.tls` 保护代码触发未处理的 `STATUS_SINGLE_STEP`（0x80000004，RVA 0x74b5950/0x47b4ac0）；游戏自身 VEH 不处理该异常码，关闭宿主 VEH 结果相同。补齐剩余 42 个锚点本身不足以绕过该保护层，当前构建维持 blocked；试验代码保留在 `feature/current-build-profile`，不进入 main。

## 备选

- 每次更新重编宿主并重发画像：实现直接，但把游戏更新成本转嫁给每位玩家，否决。
- 按版本号选择画像：同一版本号仍可能因运行时布局不同而失配，且与镜像指纹协商冲突，否决。
- 在仓库公开完整参考函数字节：违反不分发游戏资源的约束，否决。
