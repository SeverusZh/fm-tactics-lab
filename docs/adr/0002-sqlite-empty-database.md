# ADR-0002 SQLite 空库与旧数据只读归档

- 状态：已接受
- 日期：2026-11-12
- 决策者：仓库维护者

## 背景

现有持久化由 `runs/*/summary.json`、`save_library/`、`agent/drafts/` 与浏览器 localStorage 拼装，没有事务、索引或统一迁移。维护者允许新库从空开始。

## 决策

- 新版本使用单一 SQLite 文件，WAL 模式，启动时自动建库并执行迁移。
- 不迁移旧实验、旧存档库或旧草案；旧目录保留在原位置，不读取、不写入。
- 应用启动时不扫描旧目录的业务内容；用户可在文件管理器中自行查阅。
- 旧目录不被删除、重命名或改写。
- 前端不得把业务数据写入 localStorage 或 IndexedDB；只允许临时 UI 状态。

## 后果

- 升级用户的新库从空开始，旧结果不会出现在新 UI。
- 不会出现半迁移状态或双写路径。
- README 与升级提示必须明确说明旧数据只读保留。
- 未来如需导入旧数据，必须作为独立工具与独立 ADR。

## 备选

- 一次性自动迁移：需要兼容多代 schema，增加长期维护面。
- 双写 JSON 与 SQLite：产生两个 source of truth，违反解耦目标。
