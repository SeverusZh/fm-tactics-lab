# Screenshot provenance

These are real captures of the current source UI running with the v1103.2 native adapter and included example player inputs. The engine-settings static route fix on main is applied; the original published v1103.2 EXE is unchanged.

- `tactics.png`: possession and out-of-possession tactical boards and team instructions.
- `players.png`: example outfield player's attributes and whole-squad editing controls.
- `results.png`: a real paired batch, six matches per variant, seeds 42–47, full event mode, two native workers. The reference uses the default mentality; the edited home side uses Positive mentality. All 12 matches completed with zero failures.
- `save-tactics.png`: the rebuilt save tactic page with a real career save: localized league list, one entry per competition, and the selected league's teams, coaches and both preset variants. The save path is replaced with a neutral placeholder.
- `away-pool.png`: the rebuilt away tactic pool with the same league's presets imported by club, coach and tactic index.

The screenshots demonstrate the interface. The small example batch is not a recommendation for a particular tactical setting. Captures use the Chinese UI, are cropped directly from the browser viewport, and exclude local filesystem paths. No match values are inserted or retouched.
